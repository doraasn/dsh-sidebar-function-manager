# dsh-sidebar-compact · 侧栏收纳

把侧栏「全局面板」收成一条：只留你想看的入口，其余全部收进侧栏的「更多」菜单。

默认只留「聊天」，插件、跨会话消息、自动化任务等都进「更多」；进哪个、留哪个、先后顺序在
**设置 → 侧栏收纳** 里调整（勾选 + 拖动排序），改完立即生效。

## 安装

DSH 插件市场（索引源 `doraasn/dsh-plugins-index`）搜索「侧栏收纳」，或直接装：

```
github:doraasn/dsh-sidebar-compact
```

## 使用

1. 打开 设置 → 侧栏收纳。
2. 勾选要留在侧栏的面板；取消勾选的会出现在侧栏「更多」里，点开照常切换。
3. 拖动每行左侧手柄调整顺序（也可以聚焦手柄后按 ↑ ↓）；触屏没有 HTML5 拖放，改用手柄位置上的 ↑ ↓ 按钮。
4. 勾选与排序结果保存在本机 `localStorage`（键 `dsh-sidebar-compact:prefs`），桌面端和网页端各自保存。

新装的面板默认收进「更多」，不会打断侧栏布局；它的顺序排在已有面板之后。

## 实现方式

- 菜单入口来自面板自己在 `sidebar.panellist` 的注册，图标直接复用同一个组件，不另画一套图形。
- 侧栏行按 `aria-label` 隐藏：面板增减、切换语言时会重新计算规则。
- 排序通过 CSS `order` 施加到 `nav[class*="panelList"]` 的子节点上（取负值，固定排在「更多」之前），不改宿主 DOM 结构。
- 「更多」里的行挂在官方 `sidebar.panellist.actions` 槽位，点击走官方 `onOpen`，与原生入口行为一致。

## 兼容性

隐藏与排序规则依赖侧栏的 `panelList` 类名片段与面板 `aria-label`。DSH 0.2.2 起宿主在按钮外包了一层
`div.panelEntry`，选择器同时覆盖「直接子 button」与「包一层 div」两种布局。DSH 升级若再改动这两处，
表现为入口重新出现在侧栏（静默失效，不影响使用），此时改 `client.js` 里的 `panelSelector` 即可；
面板列表、图标、勾选与排序数据都不依赖这些细节。
